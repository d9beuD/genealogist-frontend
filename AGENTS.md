# AGENTS.md

## Sources Of Truth

- Use Deno, not npm/yarn/pnpm, for install and repo commands.
- `package.json` has the user-facing scripts; `deno.json` has the Nuxt task
  bodies and Deno import aliases.
- Nuxt wiring lives in `nuxt.config.ts`; shadcn-vue wiring lives in
  `components.json` and `modules/shadcn.ts`.

## Repo Shape

- Single Nuxt 4 app with Vue 3, TypeScript, and Tailwind v4.
- App code lives under `app/`.
- Feature code lives under `app/features/<feature>/`; use hexagonal boundaries:
  `domain/`, `ports/`, `application/`, `infrastructure/`, `presentation/`.
- API entities/DTOs from API Platform/Hydra responses should use shared Hydra
  types (`Item<T>`, `Collection<T>`) rather than plain DTO/array envelopes.
- Pages remain thin route adapters: keep page metadata, route-specific head
  state, and feature-view composition in `app/pages/`; keep feature logic out.
- Server proxy/middleware lives under `server/`; client API helpers call
  `/api/*`, not the backend URL directly.
- `server/api/[...path].ts` proxies `/api/*` to `runtimeConfig.apiBaseUrl` and
  forwards cookies/selected headers.
- `server/middleware/auth.ts` protects `/api/*` except
  login/register/forgot-password by validating cookies against
  `${NUXT_API_BASE_URL}/api/me`.

## Commands

```bash
deno install
deno task dev
deno task build
deno task preview
deno task generate
deno task test
deno task test:unit
deno task test:nuxt
deno task test:e2e
```

- Run a focused Vitest file with `deno task test path/to/file.test.ts`.
- Run a focused Playwright spec with `deno task test:e2e tests/example.spec.ts`.
- There is no configured lint or typecheck script; use `deno task build` as the
  main verification when tests are not enough.

## Gotchas

- `deno install` runs `nuxt prepare` through `package.json` `postinstall`.
- Set `NUXT_API_BASE_URL` for the backend; it defaults to
  `http://localhost:8000` in `nuxt.config.ts`.
- `tsconfig.json` is generated by Nuxt and should not be edited directly.
- Do not commit generated outputs: `.nuxt/`, `.output/`, `.data/`, `.nitro/`,
  `.cache/`, `dist/`, `coverage/`, `playwright-report/`, `test-results/`.
- Tailwind v4 is wired through `@tailwindcss/vite`; the CSS entry and token
  source is `app/assets/css/tailwind.css`.
- shadcn-vue uses no component prefix here. Use `<Button>`, not `<UiButton>`.
- `modules/shadcn.ts` auto-registers exports from `@/components/ui/*/index.ts`;
  keep generated UI component folders under `app/components/ui/`.
- `deno.json` excludes `app/components/ui/` from Deno lint because that
  directory is generated/vendor-style shadcn code.
- `~/lib/utils` exports `cn()` for class merging.
- OpenCode has a repo-local shadcn-vue MCP server in `opencode.json`; it shells
  out through `npx shadcn-vue@latest mcp`.
