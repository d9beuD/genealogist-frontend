# AGENTS.md

## Stack

Nuxt 4 + Vue 3 + TypeScript. This is a minimal starter — not a Nuxt 3 project.

## Commands

```
npm install        # also runs `nuxt prepare` via postinstall
npm run dev        # dev server on localhost:3000
npm run build      # production build
npm run preview    # preview production build
npm run generate   # static generate
```

## Gotchas

- `tsconfig.json` is a reference-only shim pointing at `.nuxt/tsconfig.*.json`. **Do not edit it directly** — those files are regenerated by `nuxt prepare`.
- `.nuxt/`, `.output/`, `.data/`, `.nitro/`, `.cache/`, `dist/` are all generated. Do not commit them.
- `nuxt.config.ts` uses `defineNuxtConfig` (default export). Keep it minimal; the current config only sets `compatibilityDate` and enables devtools.
- No tests, lint, or CI are configured yet.

## Components

`shadcn-vue` MCP is configured in `opencode.json`. Use the MCP tools to add components (e.g. `button`, `card`) rather than installing them manually.
